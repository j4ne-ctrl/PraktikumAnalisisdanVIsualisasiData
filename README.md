## Cara Membuka Notebook

File berekstensi `.ipynb` bisa dibuka dengan:

- **GitHub**, langsung klik filenya dan notebook akan tampil di browser.
- **Google Colab**, upload file `.ipynb` di [colab.research.google.com](https://colab.research.google.com).
- **Jupyter Notebook / VS Code**, setelah repository di-clone ke komputer.

```bash
git clone https://github.com/j4ne-ctrl/PraktikumAnalisisdanVIsualisasiData.git
```
